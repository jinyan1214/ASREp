1. Modify the ASREp_path on line 7 of the "main.py" script to your ASREp installation path.
2. The main.py script is the interface between quoFEM and ASREp.
3. The params.py defines templates for uncertainty variables to be used as Monte Carlo input.
4. Modify the paths to main.py and params.py in "quoFEM_input.json" to the correct paths in your computer.
5. Load the "quoFEM_input.json" into quoFEM.
6. Click Run
7. A summary of the run results will be found in the "response.csv" file in the quoFEM working directory.
8. For how to download and documentation of quoFEM, see https://simcenter.designsafe-ci.org/research-tools/quofem-application/
